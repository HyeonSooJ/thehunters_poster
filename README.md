# Handoff: 더헌터스 자산운용팀 성과 포스터 (1A · 1B)

## Overview
주식동아리 "THEHUNTERS" 신입 모집·홍보용 한 장짜리 세로 포스터 2종.
- **1A** — 자산운용1팀(국내주식) 누적수익률 포스터, 흰 배경. PNG로 배포.
- **1B** — 자산운용2팀(바이낸스) 누적수익률 포스터, 검정 배경. 애니메이션 GIF로 배포(카카오톡 공유용).

## About the Design Files
`posters.dc.html`은 HTML로 만든 **디자인 레퍼런스**입니다. 그대로 배포할 코드가 아니라, 목표 환경(React/Next, Python+Pillow, Remotion 등)에서 동일하게 재현하기 위한 기준입니다. 환경이 없다면 데이터(JSON/XLSX) → SVG/Canvas 렌더 → PNG/GIF 출력 파이프라인을 추천합니다. 브라우저에서 `posters.dc.html`을 열면(같은 폴더의 `support.js` 필요) 1A·1B가 나란히 보입니다.

## Fidelity
**High-fidelity.** 색, 문구, 타이포, 차트 수치까지 최종본입니다. 픽셀 단위로 재현하세요.

## Interactions & Behavior (1B GIF 타임라인)
1. 첫 프레임(썸네일)은 **완성된 최종 화면**입니다. 재생 전 미리보기용입니다.
2. 차트가 화면 아래까지 크게 시작해서 0%부터 선이 그려집니다. 세로축은 고정이고, 선이 다 그려지는 시간은 **약 0.9초**입니다. 첫 급등(10.3→10.30)은 약 0.14초, 나머지 점은 약 0.06초씩 이어집니다.
3. 차트 완료 후 0.5초 멈춥니다.
4. 0.5초 동안 차트가 축소되고, 아래 문구가 페이드인됩니다.
5. 0.8초 뒤 "달칵" 전환이 일어납니다.
   - 운영진 카드: 흰 배경/검정 글씨 → 검정 배경/흰 글씨
   - 기여도 카드: 검정 배경/흰 글씨 → 흰 배경/검정 글씨
   - 두 카드가 0.94→1 스케일로 바운스합니다.
6. 기여도 카드 둘레에 빨간 테두리가 0.5초 동안 한 바퀴 그려집니다. 선 끝에 빛나는 점이 따라갑니다.
7. 마지막 문구가 한 글자씩 타이핑됩니다(0.11초/글자). 커서(빨강)는 1.4초 주기로 5번 깜박입니다.
8. 20초 정지 후 반복합니다.

- GIF 크기는 481×837(1.3배)입니다. PC 카카오톡에서 한 화면에 보이도록 맞춘 크기입니다.
- 참고 구현: `scripts/team2_gif_generator.js`(캔버스 그리기 + 자체 GIF/LZW 인코더).
